## Getting Here

- Address: AWS Korea, 18th Floor, Centerfield EAST, 231 Teheran-ro, Gangnam-gu, Seoul
- Naver Maps: https://naver.me/xBwJytVF
- Google Maps: https://maps.app.goo.gl/hxAFnhY2x7jdhQ826

### Public Transportation

- Approximately a 9-minute walk from Exit 8 of Yeoksam Station (Subway Line 2)
- Approximately an 11-minute walk from Exit 5 of Seolleung Station (Subway Line 2)

### Building Access

Centerfield's building security team will send a visitor QR code to the mobile phone number and email address you provided when registering for the conference. Scan this code at the security gates on the first floor to enter the building. Please note that this visitor QR code is different from the QR code issued by the event platform TicketTaco, so be sure to use the correct one.
